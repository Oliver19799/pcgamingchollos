2. Qué datos recogemos

Este sitio es una página informativa estática: no tiene formularios de registro, no requiere crear cuenta y no recopila datos personales directamente a través de la web. La única forma de contacto es el correo contacto@pcgamingchollos.com, y solo se tratan los datos que la persona decida incluir voluntariamente en ese correo (nombre y dirección de email), únicamente para responder a la consulta.

El sitio está alojado mediante GitHub Pages. El proveedor de hosting puede registrar de forma automática datos técnicos básicos de las visitas (como la dirección IP o el navegador utilizado) con fines de seguridad y funcionamiento del servicio, de forma similar a cualquier servidor web. Este sitio no instala herramientas propias de analítica ni de seguimiento.

Los enlaces a productos llevan a Amazon.es como parte del Programa de Afiliados de Amazon EU. Al hacer clic y navegar por Amazon, es Amazon quien trata los datos según su propia política de privacidad, independiente de este sitio. Recomendamos consultarla directamente en amazon.es para más información.
